Kaka Nest is a static site generator built in _rust_! This was made in `Summer Hackclub 2025`
You write you blog in _ONLY_ markdown files and it transforms it into a fully functional html website.

# Usage

1. copy the 'assets' folder to your own project if you want to gte started quickly.
2. Write markdown files in the assets/blog directory.
3. run `kaka-nest build` and upload the output directory to your favorate hosting platform of choice.
4. or see it locally with `kaka-nest serve`

# Limitations

1. Setup process is meh, probably will improve in future.
2. Error messages dont tell you much, just panics if templates are erroring
